# docs/evidence 说明

这里存放**原始抓包日志**，是「没有来源的结论不合并」这条规则里的第二种来源。

## 文件命名

```
<机型>_<固件版本>_<日期>_<协议>.log
```

例：`ccpro2_1.2.3_20261012_f39.log`

## 必需内容

每个日志文件开头必须有这段头注释：

```
# 机型: FIIL CC Pro2
# 固件: 1.2.3
# 日期: 2026-10-12
# 工具: Android HCI Snoop Log
# 操作: 长按电量数字触发后门
```

然后才是原始字节，一行一个方向：

```
TX> 00 01 01 10 0F 0C 11 00 00 00 00 00 00 00 00 00 00 00 00 00
TX> 01 01 01 11 04 00 00 00 00
RX< 00 01 02 00 01
```

## 提交前脱敏

**必须删除**：

- 蓝牙 MAC 地址（替换为 `AA:BB:CC:DD:EE:FF`）
- 耳机序列号
- 手机 IMEI / 账号信息
- 任何 `activateCode` 的真实值（替换为 `00` × 32）

## 不要提交

- 从厂商服务器拿到的真实激活码
- 他人的设备数据
- 完整的 APK 或反编译产物

`.gitignore` 默认忽略 `docs/evidence/*`，只放行 `README.md` 和 `*.example`。
要提交日志时，请在 PR 里说明并用 `git add -f`。
